Skoleoverblikket

Skemaplanlegning til danske friskoler — uden Excel, uden forvirring.

Intern produktbeskrivelse · Intern brug

Problemet

Friskoler er overladt til Excel og papir

Friskoler planlægger skemaer i Excel, på whiteboards eller på papir — fragmenteret, fejlbehæftet og tidskrævende.

Konflikter (dobbeltbooket lærer, lokale) opdages manuelt — og sent. Ofte efter skemaet er delt ud.

Ingen enkelt løsning passer til den lille skoles behov og budget. Markedet er fragmenteret.

Eksisterende værktøjer: for dyre (Docendo, Skoleintra), uigennemsigtige (Skoleplan), eller kun til folkeskolen (Aula).

Hvad vi bygger (v1)

Kernefunktioner

Skemabygger

Ugentlig grid per klasse. Tildel fag, lærer og lokale. Realtidskonflikter vises direkte i gridden.

Tidslot-wizard

Definer skolens standardstruktur ved oprettelse. Per-klasse tilpasning mulig efterfølgende.

Personalestyring

Lærere, pædagoger, vikarer. Invitation via email. Roller og adgangsniveauer.

Klasse- og fagstyring

CRUD for klasser og fag. Fag knyttes til klasser via skemaet. Overskueligt og hurtigt.

Filudforsker

Upload og link filer til fag. Opbevaring via OVHCloud — EU-baseret, GDPR-compliant.

Statistik og rapportering

Timer per fag/klasse, timer per lærer. Eksport til CSV/PDF. Grundlag for UVM-rapportering.

Print-venligt skema

Per klasse, per lærer, per lokale. Printoptimeret layout. Fungerer uden appen åben.

Admin-dashboard

Overblik over skolen. Hurtig adgang til skemabygger, personale og klasser.

Betaling via Stripe

14 dages gratis prøve med fuld adgang. 299 kr/md. Selvbetjening via Stripe Checkout.
