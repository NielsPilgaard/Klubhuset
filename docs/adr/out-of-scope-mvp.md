# Out of scope for v1

**Status**: Accepted

## Decision

The following features are explicitly out of scope for v1: student grading, LMS / learning management, SMS notifications, native mobile app, folkeskole / Aula integration, accounting software integration.

Parent/student logins and parent communication are v2 candidates but not in v1.

## Reason

Building fewer things well is better than building many things poorly. The v1 is a schema planner — that is the core pain point to solve. These features can be added later based on actual school feedback. Complexity is the enemy of adoption for small schools with limited admin time.
