# ADR: Printable weekly schema views

## TL;DR

Print-friendly weekly schema views (per class, per teacher, per room) are generated by the platform, designed for A4 paper, and readable as standalone documents without the app — because friskoler physically print and post schedules.

## Status

**Accepted**

## Context

Danish schools — especially friskoler — print weekly schedules and post them physically: in classrooms, in the teachers' lounge, on notice boards. A digital-only schedule excludes this real workflow.

## Decision

The platform generates print-friendly weekly schema views: per class, per teacher, and per room. Each view includes the school name, term, and generation date so printed copies can be identified later.

## Consequences

### Positive

- **POS-001**: Supports the physical-posting workflow that friskoler already use, without requiring them to change how they operate.
- **POS-002**: Printed schedules remain identifiable (school, term, date) even when found without context.

### Negative

- **NEG-001**: Print CSS/layout must be maintained as a separate rendering concern alongside the interactive grid.

## Alternatives Considered

### Digital-only schedule views

- **ALT-001**: **Description**: Ship only the interactive in-app schema grid, no dedicated print output.
- **ALT-002**: **Rejection Reason**: excludes the physical-posting workflow that is standard practice at the product's primary target schools.
