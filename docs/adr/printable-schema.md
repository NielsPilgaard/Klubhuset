# Printable weekly schema views

**Status**: Accepted

## Decision

The platform generates print-friendly weekly schema views: per class, per teacher, and per room. These are designed for A4 paper and must be readable as standalone documents without the app.

## Reason

Danish schools — especially friskoler — print weekly schedules and post them physically: in classrooms, in the teachers' lounge, on notice boards. A digital-only schedule excludes this workflow. The printable view must include the school name, term, and date of generation so printed copies can be identified.
