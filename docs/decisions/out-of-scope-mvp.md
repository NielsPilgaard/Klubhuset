# Out of scope for MVP

**Status**: Accepted

## Decision

The following features are explicitly out of scope: booking systems, webshop/merchandise, SMS notifications, access control/door systems, accounting software integration, native mobile app.

## Reason

Building fewer things well is better than building many things poorly. These features can be added later based on actual club feedback. Holdsport's complexity is a competitive weakness — Klubhuset's simplicity is a strength.
