# Træner message permission is admin-configurable per club

**Status**: Accepted

## Decision

Whether trænere can send messages to their own teams is a per-club setting controlled by the club admin. It is off by default. Admins can always message any team regardless of this setting.

## Reason

Some clubs trust their trænere to communicate directly with team members; others prefer all communications to go through the admin. Giving admins control respects both operating styles without imposing one.
